# 📋 Project Brief

## 🧪 Project

**OrangeHRM Cypress**

Proyecto de automatización de pruebas de interfaz de usuario (UI) para la aplicación web OrangeHRM, desarrollado utilizando Cypress y JavaScript.

El proyecto forma parte del portafolio de QA Automation y tiene como objetivo demostrar la implementación de pruebas automatizadas E2E sobre un flujo de autenticación web.

---

## 📌 Description

OrangeHRM Cypress automatiza diferentes escenarios relacionados con el módulo de autenticación de OrangeHRM.

La automatización contempla escenarios positivos y negativos, permitiendo validar el comportamiento esperado de la aplicación ante diferentes condiciones de inicio de sesión.

El proyecto utiliza Cypress como framework principal para la ejecución de pruebas E2E en navegadores web.

---

## 🎯 Objectives

### Objetivo principal

Automatizar y validar el comportamiento funcional de la página de Login de OrangeHRM mediante pruebas de interfaz de usuario.

### Objetivos específicos

- Validar la correcta carga de la página de Login.
- Verificar la presencia de los principales elementos de la interfaz.
- Validar el inicio de sesión con credenciales válidas.
- Validar el comportamiento ante credenciales inválidas.
- Verificar los mensajes de validación de campos obligatorios.
- Confirmar el acceso correcto al Dashboard.
- Validar el proceso de Logout.
- Ejecutar las pruebas en diferentes navegadores.
- Mantener una estructura organizada y documentada.
- Presentar el proyecto como evidencia de competencias en QA Automation.

---

## 🧩 Scope

### Incluido

El alcance actual del proyecto comprende:

- Pruebas E2E de la página de Login.
- Validación de elementos de la interfaz de autenticación.
- Inicio de sesión con credenciales válidas.
- Validación de usuario incorrecto.
- Validación de contraseña incorrecta.
- Validación de campos Username y Password obligatorios.
- Validación de navegación hacia el Dashboard.
- Validación del cierre de sesión.
- Ejecución en Chrome.
- Ejecución en Microsoft Edge.
- Ejecución en Electron.
- Generación de evidencias mediante Cypress.
- Documentación técnica y funcional del proyecto.

### No incluido

El alcance actual no contempla:

- Automatización de otros módulos de OrangeHRM.
- Pruebas de API.
- Pruebas de rendimiento.
- Pruebas de seguridad.
- Integración con herramientas externas de gestión de casos de prueba.
- Implementación de CI/CD.
- Refactorización de la lógica de automatización existente.

Cualquier ampliación futura del alcance deberá ser registrada y gestionada mediante el roadmap del proyecto.

## 🧪 Testing Approach

La estrategia actual se enfoca en pruebas funcionales automatizadas de interfaz de usuario.

Los escenarios incluyen:

- Validaciones positivas.
- Validaciones negativas.
- Validaciones de campos obligatorios.
- Validaciones de navegación.
- Validaciones de mensajes de error.
- Validación del flujo completo de autenticación.

Las pruebas se ejecutan mediante Cypress utilizando comandos y assertions para verificar el comportamiento esperado de la aplicación.

## 🚫 Code Refactoring Policy

La etapa actual del proyecto está enfocada en la **estandarización y documentación**, no en la refactorización del código existente.

El código de automatización funcional se conserva como fue desarrollado originalmente.

La estandarización contempla principalmente:

- Organización del repositorio.
- Estructura documental.
- README.
- Convenciones de presentación.
- Evidencias.
- Documentación del estado y evolución del proyecto.
- Integración con el flujo de trabajo de Git y GitHub.

Cualquier refactorización del código deberá tratarse como una etapa independiente.
