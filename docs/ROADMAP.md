## 🚫 Out of Scope

Las siguientes actividades quedan fuera del alcance de este roadmap:

- Refactorización de tests existentes.
- Implementación de Page Object Model.
- Cambio de Cypress por otro framework.
- Automatización de nuevos módulos de OrangeHRM.
- Pruebas de API.
- Pruebas de rendimiento.
- Pruebas de seguridad.
- Implementación de CI/CD.

Estas actividades podrán evaluarse posteriormente como proyectos o etapas independientes.
